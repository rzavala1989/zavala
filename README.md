# Ricardo Zavala — Portfolio

The source for [zavala.pro](https://zavala.pro), Ricardo Zavala's staff-level software engineering portfolio.

The site is deliberately small and content-first: it makes the engineering work, decision-making, and contact path easy to evaluate without a framework-heavy application shell.

## What is here

- Case studies covering concurrent enrollment systems, a tested 3D game engine, full-stack location discovery, and public-data tooling
- A recruiter-friendly [resume](https://zavala.pro/resume/) and [FAQ](https://zavala.pro/faq/)
- Search-engine metadata, canonical URLs, sitemap coverage, and structured data
- An editorial Astro 5 interface with a D3 visualization

## Run locally

```bash
npm install
npm run dev
```

Create `.env.local` with `PUBLIC_CALENDLY_URL` to enable the scheduling link in the footer.

## Build

```bash
npm run build
```

The production site is deployed on Vercel at [zavala.pro](https://zavala.pro).
